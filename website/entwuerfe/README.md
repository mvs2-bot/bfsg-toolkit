# Entwürfe für die neue Optik (2026-10-28)

Drei Richtungen zur Auswahl, jeweils als ganze Startseite mit dem Text der aktuellen Seite. Nach der Wahl wird eine davon in `website/index.html` und `style.css` übernommen und dieser Ordner gelöscht.

- `a/`: Prüfzeichnung. Barlow und Barlow Condensed, Tusche auf Weiß, Karmin nur für Befunde.
- `b/`: Leitsystem. Atkinson Hyperlegible Next, Signalgelb und Schwarz.
- `c/`: Plakat. Permanent Marker (Überschriften) und Figtree, Papierschnitt in Kobalt, Mohnrot, Blattgrün.

Schriften in `schrift/`: Barlow, Atkinson Hyperlegible Next, Figtree unter SIL Open Font License 1.1, Permanent Marker unter Apache License 2.0 (alle über Fontsource).
Die Befunde im Kopfbereich sind Beispiele aus dem Demo-Shop, keine echten Kundendaten.
Eigener Scan (`src/scan.mjs`): alle drei Entwürfe 0 Befunde, Fokus überall sichtbar, kein seitliches Scrollen bei 320 px.
